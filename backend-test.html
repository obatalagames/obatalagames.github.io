How to read a failure

Browser fetch failure
There is no HTTP response. The page will show the exact browser exception and label the point as browser.fetch; check DevTools Network, DNS/TLS, and the edge CORS allowlist.

Edge failure
The edge response includes x-request-id, x-error-*, and a diagnostic object. The page shows the gateway stage and the exact edge code.

Worker or Supabase failure
The response diagnostic preserves the source code and stage such as supabase.rpc.... Use the request ID in Cloudflare and Supabase logs.

Expected validation failure
Placeholder IDs and bodies intentionally produce a precise 4xx contract response. That confirms the route is reachable; it is not a page defect.
